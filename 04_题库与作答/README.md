# 分科题库与作答

题目和作答按 `subject_id` 分开存放，禁止把不同科目的历史题目混在同一科目上下文中。

| 科目 ID | 目录 | 状态 |
|---------|------|------|
| `math1` | `数学一/` | 数学一，当前暂定 |
| `english1` | `英语一/` | 英语一，当前暂定 |
| `politics` | `思想政治理论/` | 思想政治理论，当前暂定 |
| `major_pending` | `专业课_待确定/` | 专业课尚未确定 |

每个科目目录下使用：

- `题目/`：题目正文和来源整理；
- `作答/`：用户作答、步骤和答案核对记录。

根目录的 `作答记录模板.md` 是通用模板，保留供复制使用；新记录应放入对应科目目录。题目数据库记录中的 `subject_id` 必须与目录一致。
