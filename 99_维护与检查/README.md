# 维护与检查

## 重要声明

- **本系统不执行任何备份。**
- **本目录不保存数据库副本。**
- 事务回滚仅用于撤销尚未提交的一次数据库操作，不是备份恢复。
- 数据安全通过事务、审批流程、变更日志和完整性检查保障，而不是通过备份。

## 目录说明

| 目录 | 用途 |
|------|------|
| `数据库检查/` | SQLite 完整性检查报告（PRAGMA quick_check / integrity_check） |
| `一致性检查/` | 数据库与 Markdown 一致性检查报告 |
| `异常记录/` | 数据库检查失败、写入异常等记录 |
| `迁移方案/` | 数据库结构变更的候选方案（待审批） |
| `人工处理说明/` | 需要人工介入的操作说明 |

## 不做的事情

- 不存储数据库 .db 文件副本
- 不存储压缩包
- 不存储 SHA 校验清单
- 不提供备份恢复流程
- 不创建任何形式的备份
